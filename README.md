# Land Parcel Area and Perimeter Calculator

## Introduction
This is a Python-based land surveying project designed to calculate the area and perimeter of a land parcel using boundary coordinates.

## Objectives
- To calculate land parcel area.
- To calculate land parcel perimeter.
- To convert area into hectares and acres.
- To save calculation results in a text file.

## Methodology
The program accepts Easting and Northing coordinates from the user.

It uses:
- Shoelace Formula to calculate area.
- Distance Formula to calculate perimeter.

## Technologies Used
- Python
- Visual Studio Code

## Project Files
- land_parcel_calculator.py
- land_parcel_results.txt

## Expected Output
Area = 10000 m2
Perimeter = 400 m
